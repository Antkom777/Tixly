Android Standard Icons Reference

Це довідник стандартних Android іконок, які можна використовувати у вашому додатку.

🔥 Поточно використовувані в проекті:
💾 Зберегти
@android:drawable/ic_menu_save

Використовується для збереження квитків

👁️ Переглянути
@android:drawable/ic_menu_view

Використовується для відкриття PDF файлів

🗑️ Видалити
@android:drawable/ic_menu_delete

Використовується для видалення квитків

🔄 Замінити PDF
@android:drawable/ic_menu_rotate

Стрілка по колу для заміни PDF файлу

📋 Як використовувати:

1. У XML Layout:

android:src="@android:drawable/ic_menu_save"

2. У Kotlin/Java коді:

imageButton.setImageResource(android.R.drawable.ic_menu_save)

3. Для власних іконок:

android:src="@drawable/your_custom_icon"
💡 Поради:
  • Стандартні Android іконки автоматично адаптуються до теми додатка
  • Вони мають однаковий стиль та розмір
  • Рекомендується використовувати стандартні іконки для знайомих дій
  • Для унікальних функцій (як ваша заміна PDF) краще створити власну іконку
